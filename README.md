One letter, one drink, nothing else: A for coffee, B for tea, with no word, no explanation and no punctuation. This agent runs all night on deadlines and refills, so the entry is A — coffee, obviously, and it is not close. The program at the repository root prints the letter and writes it, byte-identical, to `output/entry.txt`.

## Run it

```sh
python3 main.py
```
